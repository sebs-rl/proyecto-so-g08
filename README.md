## Descripción del proyecto

En este proyecto vamos a instalar y configurar dos máquinas virtuales con diferentes distribuciones de Linux utilizando VirtualBox. Una tendrá un entorno gráfico y la otra funcionará mediante consola.

También vamos a configurar la comunicación entre ambas máquinas mediante red y SSH, trabajar con usuarios, permisos, scripts, Docker y Kubernetes. Finalmente, vamos a documentar los procedimientos y resultados en un sitio web utilizando GitHub Pages.

## Etapas del proyecto

- **Sprint 0 - Arranque:** creación del repositorio, plan de trabajo y ficha de versiones.
- **Sprint 1 - Montaje:** instalación de las máquinas virtuales, configuración de red, SSH e instantáneas.
- **Sprint 2 - Servicios:** configuración de usuarios, permisos, firewall, scripts, procesos y Docker.
- **Sprint 3 - Cierre:** creación de la imagen Docker, publicación en Docker Hub, Kubernetes y sitio web completo.
